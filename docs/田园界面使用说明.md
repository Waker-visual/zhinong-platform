# 田园界面使用说明

## 今日农场

在顶部选择农场后，“今日农场”依次展示农场任务概况、地块地图、当前地块观测、土壤水分趋势和经营简报。原有巡田上报、安排农事、任务处理、现场问题复核和收获记录入口继续保留。

点击地图地块或右侧地块选择器，可切换当前关注地块。右侧分别显示土壤含水率和温度的具名测点、采集来源及时间；读数不代表地块或农场平均值。缺失值显示“—”，过期观测保留数值并标注状态。水分趋势支持 24 小时与 7 天，沿用原有历史数据与断点处理；没有记录时显示空状态。

地图和测点每分钟在页面可见时刷新，也可使用顶部“刷新数据”。切换农场或离开页面会取消旧请求，旧农场结果不会进入新农场。经营简报仍是生成时的快照，以任务台账和设备提醒判断实时变化。

地图、空间资料与测点独立读取；某个接口失败时显示重试提示，并保留其他成功读取的部分。经营简报独立展示，不因地图暂时不可用而隐藏。手动切换关注地块会清除旧设备高亮。

## 地图风格

- 农场工作台和今日农场：在“地图底图”中选择“田园插画”“卫星影像”“街道地图”或“离线平面图”。
- 展示大屏：地图左上角切换“田园插画 / 普通卫星”。
- AI 灌溉分区和手机路线预览：切换“田园插画 / 普通示意”。
- 手机农场选择器：弹层内切换“田园插画 / 普通轮廓”。

地块总览与大屏地图首次使用默认卫星影像；手机路线、灌溉与选择器简图默认普通示意或轮廓。选择偏好保存在本机浏览器。本次更新会一次性重置旧版插画默认偏好，之后主动选择的风格继续保留。后续打开地图时读取最近偏好；浏览器禁用存储时，本次页面仍可切换。风格切换不修改农场坐标、边界、设备位置、路线或业务配置。编辑布局期间禁用底图切换，避免中断当前绘制。

简图与地理底图分别记忆偏好，在简图选择“普通示意”不会让地块总览进入离线平面图。已通过“地图位置校准”明确设置的农场默认底图继续生效；定时刷新相同位置资料不会重置地图视角。

插画由原创 SVG 作物纹理绘制在已保存的地块边界内，不依赖第三方地图截图，也不发送地块图片到外部生成服务。作物纹理只表示作物类别，不表示实际行距、株数、长势或实测道路。原有 WGS84 估绘边界仍是估绘资料，普通底图保留来源署名及加载失败提示。田间插画在地块和设备范围之外增加原创树木、农舍、小径和池塘，随地图缩放移动；这些是装饰示意，不是真实地物或实测道路。三维农场维持原有三维模型与操作。

## 可折叠导航

点击侧栏的“日常作业”“农场与设备”“分析与管理”等分组标题，展开或收起该系列入口，标题右侧显示入口数量。可用 Tab 聚焦后按 Enter 或空格操作。

分组状态在本机浏览器保留；通过搜索等其他入口进入一个模块时，其分组自动展开。整个侧栏收成图标模式后仍显示所有授权入口，不因分组折叠而隐藏功能。权限筛选维持原有规则。

侧栏只有中间模块列表独立滚动，底部设置、主题和账户区固定在侧栏底端。搜索框下方新增醒目的“3D 农场”入口，直接进入三维展示；退出后焦点返回入口。窄屏继续使用原有移动导航。

“3D 农场”下方并列设置同款“小禾AI”入口，副标题为“你的专属田间助手”，点击进入 AI 助手页面。当前页面会在入口上显示选中轮廓；收起侧栏后保留图标和悬停名称，页面搜索也可找到“小禾AI”。

工作空间顶部栏固定在页面顶端，滚动时可随时切换农场、查看时间、打开时令手记和展示大屏。窄屏沿用紧凑布局，顶部栏同样固定。

## 节气手记

顶部日期左侧新增节气按钮。点击可查看当前节气、下一节气、交节时间和时令进度，并在“当季农事 / 认识节气”之间切换。支持 Esc、遮罩点击和关闭按钮退出，焦点返回入口。

点击“春生 / 夏长 / 秋收 / 冬藏”或具体节气，可漫游四季；左右箭头连续浏览，冬季的小寒和大寒自然衔接到下一年。“回到当下”恢复当前节气，浏览不会改变顶部入口、系统日期或业务记录。

点击画面中的田地、水渠、农舍可发现不同季节的农事提示，并显示本次探索进度。使用“唤一场春雨”等按钮触发短暂的场景动画；支持减少动态效果的系统偏好，动画不代表当地实况天气。关闭或切换节气后重置探索。

节气按北京时间交节时刻切换，每 30 秒及页面恢复可见时更新。日期由已有 MIT 许可的 `lunar-javascript` 在构建维护阶段生成，表覆盖 2019—2051 年；超出支持范围显示说明，不猜测日期。运行 `node tools/generate_solar_terms.cjs` 可重新生成，`--check` 用于验证。

建议是平台整理的通用季节性提示，不是实时推文、天气预报或自动农事处方。具体作业仍需结合当地气候、作物阶段和现场情况。

## 主题和验证

默认配色采用雾白底、鼠尾草绿侧栏与深绿主操作，沿用项目字体、状态语义色和原有主题设置。深色主题使用对应的田园配色。小屏布局将地图、测点与趋势依次排列；导航和弹窗支持键盘操作。

新增节气边界、跨年、闰日、地图偏好、导航存储异常与纹理输入安全测试，纳入 `scripts/verify.ps1`。在线地图验收脚本 `tools/test_map_loading.cjs` 显式选择卫星模式，继续检查瓦片加载与降级行为。
