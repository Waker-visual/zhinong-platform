# 数据链路核查报告

本轮检查覆盖录入、关系约束、历史保存、聚合统计、AI 证据和桌面/手机展示。结论是：确有会影响展示与判断的数据链问题，已修复并增加可重复核对能力；不能因此断言所有历史记录都正确。

## 确认的问题与处理

| 问题 | 原来的影响 | 本轮处理 |
| --- | --- | --- |
| 未来日期的旧生产记录进入部分汇总 | 台账、累计与近30天数值可能不一致 | 统一有效生产与日期上界，保留原始异常供核查 |
| 关联表与生产关系口径不一致 | 更正时清空的任务可能重新被旧关系补回 | 新跟踪行整行优先；关系不重复累加产量 |
| 地块跨农场移动携带经营历史 | 旧产量、任务、问题或决策悄悄变更农场归属 | 有业务历史禁止直接搬场，异常既存关系只读报告定位 |
| 采收关联和回执校验不足 | 归档记录可借更正迁出，作业面积或任务周期不匹配 | 校验原归属、种植批次面积、周期、任务状态与跟踪回执 |
| 旧观测入口未完整进入农情链 | 设备已有值，AI 却缺资料 | 统一读取与告警桥接，不重复保存遥测副本 |
| 同时刻更正选择不一致 | 页面、均值、AI、阈值告警可能引用不同值 | 统一确定次序，历史同刻只使用最终更正，告警引用实际胜出值 |
| 有效性规则分散 | 未来时刻、错误来源、维护设备或异常原值可能被误用 | 页面、AI、证据与控制统一质量规则；控制保留更严格门槛 |
| 数值单位与精度不严谨 | 土壤水分误收空气湿度单位，原值与落库舍入值不同 | 严格单位、物理范围、离散值与小数位校验 |
| 缺测与真实0混淆 | 未采到数据时曲线贴0，实际0也可能被隐藏 | 缺测留空，真实0正常显示，长缺测断线 |
| 列表长度被当总数 | 告警超过200或任务超过100时少计 | 全量计数与有上限的明细分开，明确截断 |
| 取消任务计入完成率分母 | 完成率偏低；无任务被显示为0% | 排除取消任务，无可计任务留空 |
| 实时、窗口与日报混用 | 更换时间范围后“当前健康”改变，旧日报像实时数值 | 独立当前指标可用率，标注窗口和生成时快照 |
| 时间桶混用UTC与农场偏移 | 读数可能落入相差8小时的图表位置 | 统一时间差计算，增加UTC及农场时区回归 |
| 切换农场或长时间开页保留旧状态 | 前一农场数据残留，新鲜状态无法自然过期 | 清理旧资料、隔离异步结果、按页面时钟老化 |

设备诊断图保留异常原值是为了追溯，农场与 AI 聚合排除异常；两者展示不同有明确用途。旧观测真实接收时刻无法从既有数据恢复，保留未知，新记录才保存真实接收时间。

## 重复展示与重复数据

- 首页日报摘要已去掉与实时经营卡重复的任务、产量数字，改为优先行动与生成时间；展开后保留快照依据。
- 总览、操作台账与 AI 引用同一条记录属于复用，不是重复记账；不同窗口数值不能直接比较，页面和指南已标明区间。
- 新“数据核对”按同地块、同日、同数量、同备注、同关联识别疑似重复生产组。分批采收可能合法，报告只提醒，需核实后人工更正或作废。
- 本轮没有自动删除、清洗或补造既有经营记录。

## 现有数据检查边界

包含5个标准虚构农场的独立演示实例已运行全部10项核对规则，结果为0项错误、0组疑似重复提醒。这说明该套演示数据通过当前规则，不证明农业数值真实，也不覆盖所有业务错误。

原9175实例的登录接口在本轮两次读取尝试中超时，未取得经营数据，因而没有对其历史库作出“无错误/无重复”的结论，也没有停止、覆盖或修改那份数据。更新服务后，可在“运行概览 → 数据核对”或使用本地只读工具扫描；报告将给出命中记录标识，便于逐条核实。

操作入口、统计范围、单位、接收时刻升级与命令见[数据链路与统计口径说明](数据链路与统计口径说明.md)。
