# 智禾农场桌面工作台 UI/UX 重构规格

> 版本：v1 草案 · 2026-11-16
> 状态：待用户评审，未进入实现阶段。
> 依据：[Intent](../intents/2026-11-16-workbench-redesign-intent.md)。实施步骤见[计划](../plans/2026-11-16-workbench-redesign.md)。

本规格只描述界面与交互。接口、权限、租户与业务规则保持基线行为；文中出现的数据字段均为现有接口已返回的字段。

## 1. 设计令牌

全部写在 `frontend/src/account/theme.css`。沿用现有两层结构：第一层角色色，第二层语义别名；组件只引用第二层。

### 1.1 颜色 · 浅色（田园米白）

| 角色令牌 | 取值 | 用途 |
| --- | --- | --- |
| `--light-page` | `#f6f3ea` | 页面底 |
| `--light-navigation` | `#f1ede1` | 侧栏底 |
| `--light-surface` | `#fffefa` | 卡片、面板、对话框 |
| `--light-input` | `#fffefa` | 输入框 |
| `--light-recessed` | `#f3f0e5` | 表头、内嵌区、次级底 |
| `--light-control` | `#ebe7da` | 控件悬停、中性徽标底 |
| `--light-navigation-selected` | `#dfe8d3` | 导航选中底 |
| `--light-line` | `#e3dfd0` | 分隔线、卡片描边 |
| `--light-strong-line` | `#cdc8b6` | 强调描边 |
| `--light-text` | `#18261d` | 正文 |
| `--light-secondary` | `#48564b` | 次级文字 |
| `--light-label` | `#5f695b` | 标签、说明 |
| `--light-muted` | `#7d8474` | 仅装饰与分隔符 |

| --- | --- |
| `--dark-navigation` | `#101814` |
| `--dark-page` | `#141d18` |

| `--dark-selected` | `#2f4035` |

| `--accent-forest-dark` | `#a6c995` |
| `--accent-forest-dark-soft` | `#23382a` |

状态色（`--ok`、`--info`、`--amber`、`--caution`、`--danger` 及其底色与线色）保持现值，只在实现时用脚本复核它们在新底色上的对比度；不达标的按最小幅度加深或提亮。

蓝、琥珀、玫红三个可选主题色保留。设置里“默认”主题色的色样与预览随 `--accent-forest` 变为田野绿，存储值仍为 `FOREST`，不迁移数据。后端只接受 `FOREST|BLUE|AMBER|ROSE` 四个取值，本轮不新增枚举，原黑白主题不再可选。

上表取值已用 `node tools/check_contrast.cjs` 实测：浅色与深色、四种主题色共 110 组组合全部达标（2026-11-16）。实测中调整了三处：标签色由初稿的 `#667062` 加深为 `#5f695b`，深色标签色提亮为 `#97a492`，蓝色主题色由 `#2563eb` 加深为 `#1d4ed8`（原值在浅底上为 4.24:1，属基线已有问题）。

手机端入口（`frontend/src/mobile/main.js`）同样引入 `theme.css`，角色色变化会同步影响手机端；展示大屏在 `.farm-display` 内覆盖了大部分令牌，但仍继承未覆盖的别名（如 `--primary-bg`）。两者都须在浅色与深色下回归。

### 1.3 对比度要求

实现阶段用脚本对下列组合逐一计算，写入验收记录：

- 正文、次级文字、标签对页面底与卡片底：≥ 4.5:1。
- 主按钮文字对主题色：≥ 4.5:1。
- 输入框描边、图表色块、状态点对其底色：≥ 3:1。
- 浅色与深色两套都要过。

### 1.4 字号阶梯

新增令牌，逐步替换散落的像素值。承载信息的文字不小于 12px；地图标注与图表刻度可用 11px。

| 令牌 | 字号 / 行高 / 字重 | 用途 |
| --- | --- | --- |
| `--text-caption` | 12 / 18 / 400 | 元信息、时间、单位、表头 |
| `--text-small` | 13 / 20 / 400 | 次级正文、表格单元、徽标 |
| `--text-body` | 14 / 22 / 400 | 正文、按钮、输入 |
| `--text-title` | 16 / 24 / 600 | 卡片标题、列表主行 |
| `--text-section` | 20 / 28 / 600 | 区块标题、农场名 |
| `--text-page` | 24 / 32 / 600 | 页面标题 |
| `--text-figure` | 32 / 36 / 600 | 指标数字 |

数字统一 `font-variant-numeric: tabular-nums`。指标数字与单位：数字用 `--text-figure`，单位用 `--text-small` 与 `--label-fg`，基线对齐，间隔 4px。字体不更换。

### 1.5 间距、圆角、层次

- 间距刻度：`--space-1`…`--space-7` = 4 / 8 / 12 / 16 / 24 / 32 / 48。卡片内边距 16 或 24；卡片间距 16；区块间距 24；页面左右边距 32（≤ 760px 时 16）。
- 圆角沿用 `--radius-xs` 4、`--radius-sm` 8、`--radius` 12、`--radius-lg` 18；卡片用 12，页面级主体卡（农场头图带、地块示意）用 18，控件用 8。
- 层次三级：平面（1px 描边、无阴影，默认卡片）；浮起（`--shadow`，可点击卡片悬停、粘性表头）；覆盖（`--shadow-lg`，菜单、对话框、浮窗）。不叠加描边与重阴影。

## 2. 应用外壳

### 2.1 模块与页面

`frontend/src/catalog.js` 新增 `modules`，每项含 `id`、`title`、`icon`、`pages`（页面 `id` 数组，首项为模块默认页）。页面定义 `menus` 保留，`group` 字段改由模块推导。

| 模块 `id` | 标题 | 页面（按页签顺序） |
| --- | --- | --- |
| `today` | 今日农场 | `daily` |
| `land` | 农场与地块 | `dashboard`、`farms`、`plots`、`plantings` |
| `work` | 农事与生产 | `tasks`、`production` |
| `devices` | 设备与监测 | `operations`、`devices`、`cameras` |
| `insight` | 智能分析 | `ai`、`simulation`、`display` |
| `admin` | 管理 | `members`、`audit` |

- `members` 仅管理员可见；模块内没有可见页面时模块不显示。
- 平台管理员只看到“租户管理”，不显示模块。
- `display` 是动作而非页面：在页签中点击即打开展示大屏，页签不进入选中态；顶栏“展示大屏”按钮保留。

### 2.2 侧栏

- 宽 232px，收起 64px；过渡曲线不变。
- 自上而下：品牌 → 租户与角色 → “搜索页面… Ctrl K” → 模块列表 → 底部账号区。
- 模块行高 40px，图标 18px，文字 `--text-body`。选中：`--nav-selected-bg` 底、左侧 3px 主题色竖条、文字与图标取 `--text`、字重 600。悬停：`--control-hover`。
- 点击模块进入该模块上次停留的页面；首次进入为默认页。
- “今日农场”保留计数徽标与读屏说明（`#attention-note`）。
- 侧栏在视口高度不足时内部滚动，底部账号区始终可见。
- 每个模块按钮的可访问名称为模块标题。单页模块选中时带 `aria-current="page"`；多页模块选中时带 `aria-current="true"`，当前页由模块页签的 `aria-current="page"` 表示。

### 2.3 顶栏

高 56px。左：面包屑“模块 / 页面”（单页模块只显示页面名）与当前农场选择。右：日期、同步状态胶囊、展示大屏、提醒。日期使用 `--text-caption` 与等宽数字，不再出现字距过宽的观感。

### 2.4 页面标题区与模块页签

- 标题 `--text-page`，说明 `--text-small` 与 `--label-fg`，右侧为页面级操作（最多一个主按钮）。
- 标题区下方为模块页签 `nav.module-tabs`（`aria-label="模块名"`），每个页签是按钮，可访问名称为页面标题，当前页 `aria-current="page"`。样式：文字页签加 2px 主题色下划线，间距 24px，高 40px。
- 单页模块不渲染页签。
- “刷新数据”从大按钮改为标题区右侧的次级按钮，名称与行为不变。

### 2.5 其他

- 命令面板按模块分组列出全部页面，行为不变。
- 底部标签栏（≤ 760px）保持现有四项加“更多”。
- 页脚保留版本号，文字 `--text-caption`。

## 3. 通用部件

| 部件 | 规格 |
| --- | --- |
| 指标卡 `.kpi` | 内边距 16；标签（`--text-caption`）→ 数字加单位 → 一行说明；一组中至多一张“主卡”用主题色实底与 `--on-brand` 文字；需处理的状态用顶部 2px 状态色线加数字着色，不整卡变色 |
| 面板 `.panel` | `--surface` 底、1px `--border`、圆角 12、内边距 24；标题行：标题（`--text-title`）、可选计数、右侧次级操作 |
| 按钮 | 高 36（紧凑 32）；主按钮 `--primary-bg`；次级为描边；文字按钮无底；危险操作仅在确认处使用实底危险色；图标 16px 与文字间隔 8 |
| 状态徽标 `.badge` | 高 22、圆角 6、`--text-caption`、600；语义色浅底加深字；同一含义全站同一颜色与措辞 |
| 表格 | 表头 `--subtle-bg`、`--text-caption`、`--label-fg`；行高 48（两行内容 60）；行悬停 `--subtle-bg`；数字列右对齐；操作列至多两个文字按钮，其余收入“更多” |
| 页签与分段 | 页面级用下划线页签；面板内筛选用分段控件（`--sunken` 底，选中为 `--surface` 加轻阴影） |
| 折叠说明 | 口径、数据说明统一为区块标题右侧的“口径说明”文字按钮，展开内容在区块下方；保留 `<details>` 语义 |
| 空状态 | 图标（AppIcon，24px，`--label-fg`）、一句说明、一个下一步按钮；不放大号插画 |
| 骨架屏 | 沿用 `.skeleton`，形状与最终布局一致 |
| 图表 | 序列色取作物与模块令牌；网格线 `--border`；轴文字 `--text-caption`；无数据时显示空状态而非空坐标轴 |

图标一律使用 `frontend/src/ui/AppIcon.vue` 线性图标（描边 1.7，16 或 18px）。运行概览中的位图图标（`/icons/operations/*.png`）替换为 AppIcon；缺少的图标在 AppIcon 中按同一画法补充。

## 4. 页面规格

### 4.1 今日农场（样板页）

回答的问题：**今天先做什么。**

1440×900 首屏自上而下：

1. **农场头图带**（`--brand-soft` 底，圆角 18，内边距 24）
   - 左：农场名（`--text-section`）；元信息“N 块田 · M 亩 · 角色”。
   - 中：优先任务。存在可处理的优先任务时显示“先处理：{任务名}”与主按钮“开始任务”或“完成回执”（沿用 `priorityTask` 与 `canWork` 判定）；否则显示角色对应的引导语。
   - 右：快捷操作——巡田上报、安排农事、记录收获、农场地图、季度方案对照（次级按钮；没有优先任务时“巡田上报”为主按钮）。
2. **首屏主体**（12 栏网格，间距 16）
   - 左 7 栏 · **地块示意**（新组件 `fieldwork/PlotOverview.vue`）：以 `/farm-workspaces` 返回的 `plots[].boundary` 绘制台账地块（不是农场地图的小田块 `field-map` 数据），视图框按全部边界的外接范围加留白自适应，不绘制装饰性的道路与河流；按作物着色（`cropColor`），标注地块名与面积；地块上有未结束的逾期任务、受阻任务或未关闭现场问题时显示对应状态点（数据来自 `/field-work` 的 `tasks` 与 `issues`，按所属地块归并）。右侧图例列出地块、作物、面积（取代原“我的地块”卡）。点击地块或“打开农场地图”进入农场概览。没有边界数据时显示“待绘制地块”空状态与入口。标注“示意图，非测绘成果”。
     样板页阶段先用演示农场真实数据渲染评估：若自适应后的图形仍不足以充当首屏主体（地块过少、形状过于简单），改为“地块卡片阵列”（每块一张：作物色条、名称、面积、作物、状态点），字段与交互相同。
   - 右 5 栏：上为 2×2 指标卡（农场待办为主卡；逾期、受阻、现场问题按状态着色），标题行右侧为“口径说明”；下为今日经营简报（沿用 `FarmBriefing` 紧凑形态）。
3. **农事与现场**（12 栏）
   - 左 8 栏 · 农事队列：标题、筛选分段（待处理 / 受阻 / 已结束 / 全部）、“只看我负责 / 未分配”、搜索。任务行压缩为两行：第一行状态徽标、任务名、计划日期（右对齐）；第二行“地块 · 类型 · 负责人”与作业方式；受阻原因作为行内提示条。行尾为一个主操作（开始任务 / 完成回执）与“更多”菜单（报告受阻、调整安排、记录、取消）。备注超过一行截断，展开查看。
   - 右 4 栏 · 现场问题：流程提示一行；问题卡含地块、优先级徽标、描述、来源与状态、一个操作。已关闭问题折叠。

移除右下角“无人机缺位，如何补位？”虚线卡，入口由“季度方案对照”承担。

保留：`.daily-farm`、`.daily-task`、`.daily-dialog` 类名与全部对话框流程。

### 4.2 农场概览与单农场工作台

回答的问题：**这座农场现在怎么样。**

- 农场列表（`FarmHub`）：卡片含缩略图、名称、地区、三项数字（地块、面积、设备）与待办数；演示标识用徽标。
- 工作台头部并入页面标题区：农场名、地区与演示标识在左；“15 秒刷新”“刷新工作台”“大屏模式”在右，“大屏模式”为主按钮。
- 指标行：五张指标卡，经营面积为主卡。
- 主体：左为地图面板，右为“田块设备 / 农机作业 / 分区灌溉”页签面板。地图面板的标题栏与工具栏随页面主题（浅色下为浅底）；只有影像区及其叠加物使用 `--on-image` 一组令牌。图层开关改为紧凑的勾选胶囊；“环境监测与四情数据”折叠条移到地图面板下方。保留 `.workspace-main-grid`、`.farm-map-panel` 与 `data-load-state`。
- “经营与环境数据”：三张环图合为一行等高卡；图例放在图右侧并直接标数值。收获产量趋势与环境监测趋势并排。
- 设备点位清单：默认只列出需要关注的设备（暂无有效读数、待处理告警），其上显示一行汇总“16 台中 16 台读数有效”；可切换“全部”。
- 措辞：“有有效指标”改为“读数有效”，“暂无有效指标”改为“暂无有效读数”，全站一致。

### 4.3 运行概览

回答的问题：**设备与作业是否正常。**

- 今日经营简报置顶保留。
- 三张指标卡改用 AppIcon；链接改为卡片右上角文字按钮。
- “设备上报与土壤水分”：标题、统计范围、平均健康度在同一行；图例在图下方；说明文字用 `--text-caption`。
- “作业流水线”四张卡：模块色块缩为 36px 图标底，图标用 AppIcon；状态用徽标。
- “地块 × 日期 · 土壤水分”：行标签左对齐、色块等宽；图例在右上。
- “统计口径”“数据核对”按 §3 折叠说明处理。保留 `.ops-slice`。

### 4.4 设备台账与设备详情

回答的问题：**这台设备在干什么、数据可信吗。**

- 顶部五项数字合为一条汇总带（一张卡内五列），“汇总范围”说明并入其标题行。
- 表格每行两行内容：设备名加类型图标与编码；农场 · 地块；状态徽标与“N / N 项读数新鲜”；最新两项读数（其余“共 N 项”）；采样时间（相对时间，悬停显示绝对时间）。操作列：“详情”加“更多”（编辑、采集、查看画面）。保留 `[data-device-id]`。
- “从设备建档到数据进入大屏”四步说明改为“接入说明”折叠。
- 设备详情：顺序为身份与状态 → 当前任务 → 读数（数值、单位、阈值范围、采样时间、来源）→ 历史记录。模拟设备的“模拟”标识保持可见。

### 4.5 农场 AI 助手

- 页面标题区右侧保留小禾伴随条。
- 四个页签（农事对话 / 决策闭环 / 天气与四情 / 灌溉管理）使用 §2.4 的下划线页签样式。
- 对话空状态：标题 `--text-section`，四张建议卡等高、圆角 12、悬停浮起。
- 输入区：圆角 12、聚焦环用主题色；说明文字 `--text-caption`。
- 决策卡、证据、活动记录的结构与文案不变，只对齐令牌与间距。保留 `.ai-*` 类名与 `#floating-question`。

### 4.6 经营模拟

- 首卡改为与今日农场一致的头图带（标题、一句说明、天气数据标识）。
- 预设情景为可选卡片（标题加一句结果预期），选中态用主题色描边。
- 参数表单一行四到五项，折叠项用 §3 折叠说明；“运行三方案对照”为页面唯一主按钮，位于表单卡右下，且不被小禾遮挡。
- 结果区沿用现有图表与事件列表，按 §3 图表规则统一。模拟性质说明保留。

### 4.7 通用列表页

农事任务、生产记录、农场档案、地块管理、种植计划、成员权限、操作日志：

## 5. 响应式、主题与动效

- 断点：≥ 1200px 为完整多栏；900–1199px 首屏主体与农事区改为上下堆叠；≤ 760px 侧栏隐藏、启用底部标签栏、页面边距 16。
- 深色主题下所有页面按 §1.2 取色；地图影像区不随主题变化。
- 动效：悬停与选中 150ms；面板展开、页签切换 200ms；`prefers-reduced-motion: reduce` 时取消位移与缩放，仅保留不透明度变化。
- 首屏不引入新的大图或运行时依赖。
