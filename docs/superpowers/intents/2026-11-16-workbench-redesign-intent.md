# 智禾农场桌面工作台 UI/UX 重构 · Intent

> 版本：v1 草案 · 2026-11-16
> 状态：待用户评审，未进入实现阶段。配套[规格](../specs/2026-11-16-workbench-redesign-design.md)与[计划](../plans/2026-11-16-workbench-redesign.md)已按本文起草，一并评审。
> 基线：`origin/main` `c4cf783`（2026-10-20）。

## 1. 为什么要做

智禾农场要以“生产级 AI 创新软件”的标准参赛。评委会先看一眼截图，再点进去追问。当前桌面工作台功能完整，但两关都过不稳。

对基线版本做了本地走查（1440×900，浅色与深色，13 个页面），问题按影响排序：

| # | 现象 | 证据 | 后果 |
| --- | --- | --- | --- |
| 1 | 品牌色缺席 | 默认主题 `FOREST` 在 `theme.css` 中实际为黑白（`--accent-forest: #18181b`）；绿色只出现在标志与状态点 | 截图看不出是农业产品，与登录页、标志、小禾的田园气质脱节 |
| 2 | 首屏没有主体 | “今日农场”首屏是 4 张等权指标卡加 9 张等权任务卡；地图在“农场概览”第二屏，且为黑色面板 | 一眼看不到“这座农场现在怎么样”，空间与任务分离 |
| 3 | 层级扁平 | 11–13px 字号占全部声明的约 80%；间距有 20 余种取值；卡片、列表、表格视觉权重相同 | 信息密度高却读不出主次 |
| 4 | 导航过长 | 侧栏 14 项平铺，三组标题只是分隔 | 找页面靠扫读，演示时来回跳 |
| 5 | 细节硬伤 | 小禾悬浮入口（104×116px，固定在右下角）下方没有安全留白，页面滚到底时仍压住右下角的数字与操作（如农场档案卡片的“待办”与“删除”）；设备台账单行高达 5 行文字；“有有效指标”叠字；口径说明折叠条散落各处 | 经不起推敲 |
| 6 | 工作台与大屏落差大 | 展示大屏（深色）完成度明显高于日常工作台 | 从大屏返回工作台时质感断档 |

## 2. 要达到什么

一句话：**让桌面工作台第一眼是一款农业产品，第二眼看得出主次，点进任何一页都经得起追问。**

可检验的结果：

1. **识别度**：任意一张工作台截图，遮住标志仍能认出是智禾农场——米白底、田野绿、金色点缀，与登录页和标志同源。
2. **首屏主体**：1440×900 下，“今日农场”不滚动即可同时看到地块示意、当前最该处理的一件事、关键指标与今日简报。
3. **层级**：全站只用一套字号阶梯与间距刻度；每个页面有且只有一个主操作。
4. **导航**：侧栏一级入口不超过 6 个；任何原有页面两次点击内可达；页面标识、权限与功能不变。
5. **诚实**：界面上每个数字都能指到现有接口字段；模拟、演示、规则分析、非实时等标识一个不少；不为版面好看而新增指标。
6. **无回归**：`scripts/verify.ps1` 通过；深色主题、375px 窄屏、减少动态效果偏好下均可用；包体预算不超。

## 3. 已确认的决定

2026-11-16 与用户商讨确定：

| 议题 | 决定 | 含义 |
| --- | --- | --- |
| 视觉方向 | **A 田园米白** | 米白页面底、田野深绿主色、金色点缀、浅色侧栏；不采用深绿侧栏的通用后台样式 |
| 范围与顺序 | **桌面工作台优先** | 先做设计令牌、外壳与“今日农场”样板页，用户看过真实截图确认后再铺开其余页面；大屏只做小修；手机端留到下一轮 |
| 后端范围 | **纯前端，只用现有字段** | 不新增接口与表结构；参考图里我们没有数据的指标（如“植物健康 94%”“支出”）不做 |
| 导航结构 | **合并为约 6 个一级模块** | 原页面成为模块内页签；页面 `id` 不变 |

## 4. 设计原则

出现取舍时按此顺序裁决：

1. **数据诚实先于版面饱满。** 没有数据就显示“未记录”，不补造；来源、单位、时间跟着数字走。
2. **一屏一个主体。** 每个页面先回答一个问题（今天先做什么、这块地怎么样、这台设备在干什么），其余信息围绕它排布。
3. **空间与任务同屏。** 地块示意、设备与任务尽量出现在同一视野，选中对象在列表、图与详情之间保持一致。
4. **层级靠字号、字重与留白，不靠边框和色块堆叠。** 强调色只给主操作与需要处理的状态。
5. **借鉴结构，不照搬界面。** 参考产品用于学习信息组织；品牌、图形、文案与数据均为智禾自有。
6. **动效解释变化。** 只为选中、展开、状态更新提供 150–250ms 过渡；尊重减少动态效果偏好。

## 5. 范围

**本轮包含**

- 设计令牌：浅色与深色两套田园配色、字号阶梯、间距刻度、圆角与阴影层次。
- 应用外壳：侧栏（6 个模块）、顶栏、页面标题区、模块内页签、底部标签栏、命令面板分组。
- 样板页：今日农场（首屏重排）。
- 铺开：农场概览与单农场工作台、运行概览、设备台账与设备详情、农场 AI 助手、经营模拟、通用列表页（农事任务、生产记录、农场档案、地块管理、种植计划、成员权限、操作日志）。
- 通用部件：指标卡、面板、表格、状态徽标、按钮、空状态、骨架屏、折叠说明。
- 小禾悬浮入口的默认停靠位置，避免遮挡正文与主按钮。
- 随改动更新：使用说明、`docs/images` 与 README 预览图、CHANGELOG、界面字体子集。

**本轮不包含**

- 后端接口、数据库与权限模型的任何改动。
- 手机端（`frontend/src/mobile/`）与 Android 应用的结构与交互。注意：手机端入口与桌面共用 `theme.css`，配色会随令牌一起变为田园米白；本轮只保证它换色后不退化（对比度与可读性回归），不做重排。
- 展示大屏的结构性改版（仅在共用令牌变化时保证不退化，并修正明显瑕疵）。
- 登录页字符画场景。
- 新业务能力：历史回放、计划拖拽、遥感接入、参数化植物、新的 AI 工具。
- 引入 UI 组件库或新的运行时依赖。

## 6. 约束

- **技术栈不变**：Vue 3 + 原生 CSS + ECharts + Leaflet + Three.js。参考文档提到的 Element Plus 以“沿用现有框架”为前提，不引入。
- **颜色只在 `frontend/src/account/theme.css` 定义为令牌**，组件引用语义别名；`tools/check_project.cjs` 会拦截其他位置的色值字面量。深色主题同步维护。
- **字体**：界面汉字来自按 `unicode-range` 切片的思源黑体子集；新增界面汉字后须运行 `tools/subset_fonts.py` 并通过 `tools/check_fonts.cjs`。该检查按 `<div v-if="!identity" class="login-layout">` 与 `<div v-else` 两个标记截取 `App.vue` 的登录首屏文字，改外壳时这两个标记必须原样保留。
- **包体预算**：单个脚本块 ≤ 500 kB，样式表 ≤ 200 kB，入口首屏脚本合计 ≤ 1400 kB（`tools/check_bundle.cjs`）。
- **权限与租户**：角色、租户、临时密码拦截、平台账号不读经营数据等逻辑一律不动；`App.vue` 以改模板与样式为主，脚本只做导航分组所需的最小改动。
- **可访问性**：保留现有 ARIA 角色与标签、焦点管理、键盘操作与 44px 触控热区；正文对比度不低于 4.5:1。
- **测试选择器**：浏览器验收脚本依赖 `#app-sidebar`、`.daily-farm`、`.daily-task`、`.workspace-main-grid`、`.farm-map-panel`、`[data-device-id]`、`[data-parcel-id]` 等选择器以及“今日农场”“农场概览”“田间实景”“刷新数据”“当前农场”等可访问名称；重构时保留，确需变更则同步修改脚本。
- **素材**：不提交参考网站截图、Dribbble 作品与微信转来的参考文档；`private-materials/` 等路径受公开范围检查保护。
- **并行协作**：仅在本 worktree 与分支内工作，按小步提交，每步通过 `scripts/verify.ps1`。

## 7. 默认取值（如不同意请在评审时指出）

以下未单独询问，按默认推进：

1. **模块划分**

   | 一级模块 | 包含页面 |
   | --- | --- |
   | 今日农场 | 今日农场 |
   | 农场与地块 | 农场概览、农场档案、地块管理、种植计划 |
   | 农事与生产 | 农事任务、生产记录 |
   | 设备与监测 | 运行概览、设备台账、田间实景 |
   | 智能分析 | 农场 AI 助手、经营模拟、展示大屏 |
   | 管理 | 成员权限、操作日志（仅管理员可见） |

   平台管理员仍只看到“租户管理”。

2. **字体**：继续使用思源黑体与 Iosevka Aile，不换字体；通过字号阶梯、等宽数字与字距调整消除目前数字偏“终端”的观感。
3. **今日农场首屏**：左侧为地块示意，右侧为“当前最该处理的一件事”、四项指标与今日简报；农事队列与现场问题在其下。地块示意画的是台账里登记的地块（演示农场为 3 块），不是农场地图上的 9 个小田块；现有边界数据在农场档案缩略图里只是三个小矩形，需按边界范围自适应放大后才能作为首屏主体，样板页阶段以真实渲染效果为准，效果不足则改用地块卡片阵列。
4. **小禾悬浮入口**：位置、尺寸与拖动不变（此前按用户要求放大过，验收脚本有断言）；改为给页面底部留出安全留白，使任何内容都能滚出它的遮挡范围。
5. **深色主题**：改为带绿调的深色，与大屏的湖蓝田野绿靠拢，不再是纯灰黑。
6. **主题色选项**：设置中的“默认”主题色由黑白改为田野绿；蓝、琥珀、玫红保留。主题色取值由后端校验（`FOREST|BLUE|AMBER|ROSE`），纯前端范围内无法新增第五个选项，因此**原来的黑白主题将不再可选**。如需保留，要么放宽“纯前端”约束加一个枚举值，要么让出蓝、琥珀、玫红中的一个位置。

## 8. 验收方式

- 每个阶段结束提供 1440×900 浅色、深色与 375px 截图，与基线并排对比。
- 样板页经用户确认后才铺开其余页面。
- 全部完成时：`scripts/verify.ps1` 通过；受影响的浏览器验收脚本通过；逐页自查清单（比例、图标、对齐、空状态、加载态、错误态、长文本）无遗留。
