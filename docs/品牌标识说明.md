# 智禾农场品牌标识

“禾生”以禾苗、金色新叶和田垄组成图形：禾苗代表持续生长，金色新叶寄托智慧与收获，田垄代表经营扎根于土地。圆角方形便于在导航栏和浏览器标签中保持一致轮廓。

## 资源与使用

- 主图标：[zhihe-logo.svg](../frontend/src/assets/zhihe-logo.svg)，64 × 64 矢量画布，不依赖字体、外部图片或网络请求。
- README 横幅：[banner.svg](images/banner.svg)，内嵌相同图形，便于 GitHub 直接显示。
- 登录页使用 40 px 图标，桌面导航使用 34 px，移动端页头使用 28 px；浏览器标签页复用主图标。
- 独立插图建议使用 64 px 及以上，四周至少保留图标宽度的四分之一作为留白；不得拉伸或裁切。

品牌色固定为田园深绿 `#234D3C`、谷物米白 `#F5F2E6` 和麦穗金 `#DFBC70`，在深浅界面及不同操作主题色下保持一致。标识没有阴影、渐变或动画。

主图标为本次绘制的矢量路径，未使用第三方图标或字体轮廓；仓库既有权属与第三方许可约定不变。更新标识时，应同时更新主图标与 README 横幅中的图形，并检查浅色、深色及小尺寸显示。
