# 智禾农场 0.2.0 功能与操作指南

本版把农场档案扩展为可操作的地图和数据工作台。图表来自已保存的地块、设备、农事和生产记录；演示农场的名称、布局和数据均为虚构，界面有相应标识。

## 启动与首次浏览

在 Windows PowerShell 中运行：

```powershell
Set-Location '<项目目录>\zhinong-platform'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-demo.ps1 -SkipBuild
```

浏览器打开 http://127.0.0.1:9175 。租户代码填 `demo-a`，账号填 `admin`，密码使用启动窗口显示的本机演示口令。若修改了源码，去掉 `-SkipBuild` 重新构建。已有数据库保留原密码和业务记录。

登录后，在“农场概览”点击 **青禾综合示范农场的图片**。可以依次查看：

1. 六个地块的布局、八个设备点位、不同作物颜色及设备上报状态。
2. 点击设备标记，在侧栏查看所属地块、编码、多指标读数、数据来源和最近上报时间。有待处理告警的标记右上角带圆形“!”，超时未报的带方形“…”；悬停或用读屏软件可听到设备名称和状态。
3. 点击“完整详情与历史”，切换指标、24 小时 / 7 天 / 30 天，缩放曲线，导出当前指标的汇总 CSV。
4. 下方查看作物面积、设备分类、农事状态三张饼图，以及产量柱图和环境趋势。点击饼图分类会筛选地图或任务列表；“清除筛选”恢复全部。
5. 点击“大屏模式”，同屏展示地图和图表，点击设备切换趋势，点击“设备详情”查看完整记录。退出按钮或 Esc 返回普通工作台。

“15 秒刷新”只重新读取数据库，不会自动捏造新测量。刚启动时，历史演示数据可能显示“超时未报”；点击模拟设备的“模拟采集”可生成带来源标签的新样本。

## 导航与快捷操作

- 左侧菜单按“日常作业”“农场与设备”“分析与管理”分组。“今日农场”旁的数字是本租户全部农场中逾期、受阻（不含已逾期）和待处理现场问题的合计：有逾期时显示红色，只有受阻时显示橙色。数字随每次切换页面刷新。
- 顶栏的“当前农场”切换各页面共用的具体农场；今日农场、运行概览和经营模拟必须选定一座农场。设备台账的农场筛选留空时表示不限定农场，选项菜单只列出具体农场。
- 农场选项菜单跟随当前深浅主题绘制，选中和悬停状态使用对应的文字与控件令牌。
- 详情、设置和命令面板中的长内容使用容器内滚动；滚动轨道透明，圆角滑块按当前主题取色，不会在圆角边界外形成直角边栏。
- 今日农场、运行概览和农场工作台的指标下方有“统计口径”，展开可看每个数字的计算范围。
- 点击保存、删除、启停等按钮后，只有被点的按钮显示转圈，其他按钮在保存完成前暂不可用，防止重复提交。
- 点击侧栏顶部的收起按钮，侧栏缩为图标栏；悬停图标显示页面名称。浏览器会记住收起状态，下次登录保持不变。
- 按 Ctrl K（macOS 为 ⌘K）或点击“搜索页面…”打开页面搜索，输入页面名称后用方向键选择、回车进入，Esc 关闭。账号设置、深浅主题切换和退出登录也可以从这里找到。
- 外观设置选择“跟随系统”时，按浏览器本地时区自动切换：标准时 07:00–18:00 使用浅色，其余时间使用深色；夏令时调整为 06:00–20:00。侧栏底部的月亮按钮可改为固定的浅色或深色，并保存到当前账号。
- 手机上左侧菜单收进底部标签栏，显示今日农场、农事任务、农场概览、设备台账等常用页面；其余页面和账号操作在“更多”里。
- 今日农场的任务卡只保留当前最该做的一步：执行人看到“开始任务”或“完成回执”，旁边是“报告受阻”；查看记录、调整安排和取消任务收进带图标的“更多”浮层菜单，菜单使用圆角边框和阴影，取消任务以红字显示。任务按逾期、受阻、计划日期排序。
- 删除农场或地块不再弹确认框：记录先从列表消失，右下角提示条上 6 秒内可点“撤销”，底部细线显示剩余时间，鼠标悬停或键盘聚焦时暂停计时。计时结束、点 × 关闭提示、离开页面或退出登录时才真正删除。还有地块、设备或农事任务的农场和地块会直接说明原因，不进入撤销。
- 重新生成设备接入凭据会立即作废旧凭据、无法撤销，因此仍先弹出确认框，写明后果；焦点默认在“取消”，按 Esc 即取消。
- 新增、编辑表单和录入监测数据使用对话框：打开后可直接输入，Tab 不会跳到背后的页面，按 Esc 或点击遮罩关闭（保存过程中不会被关闭）。
- 切换页面时，加载超过 0.1 秒会在页面顶部出现进度条。今日农场、农场档案、农场工作台、设备台账、运行概览和各列表首次读取时，先显示与真实版式一致的灰色占位并带扫光，数字位不会先显示 0；经营模拟在计算或读取方案期间先隐藏上一份结果、显示占位，避免把旧数字当成新结果；在同一页面刷新时保留现有内容，新数据到达后再替换。系统设置为“减少动态效果”时占位不扫光。
- 保存成功等结果提示出现在右下角（手机上在标签栏上方），几秒后自动消失。
- 成员权限和租户管理里的“启用 / 停用”点下立即生效，不再锁住其他按钮；请求失败时状态自动恢复，并给出常驻报错。自己的账号显示“当前登录账号”，不能停用。
- 操作失败的报错同样出现在右下角，但不会自动消失，需点 × 关闭；网络或服务端故障时带“重试”。表单和登录的报错显示在表单里。
- 顶栏右侧的状态胶囊显示与本地服务的连接：“已同步 10:42”是最近一次成功通信的时间，请求较慢时显示“正在同步…”，服务无法连接时变红并在页面顶部提示，点击胶囊即重新读取当前页面。手机上只在连接中断时显示“离线”。

## 运行概览

左侧菜单“农场与设备”下的“运行概览”把一座农场的运行状况放在一页，适合每天开工前扫一眼。所有角色都可查看，平台账号没有这个页面。

1. 顶部三张指标卡：农场待办（含逾期、受阻数）、此刻设备上报健康度、未关闭的现场问题。卡片配有纸张清单、传感器波形和地图告警三组双元素线描图标；点击卡片右下角的链接进入今日农场或设备台账。
2. “设备上报与土壤水分”把所选范围（近 24 小时 / 7 天 / 30 天）等分为 100 个时间片。每根色条是该时段结束时仍按时上报的启用设备比例：绿色 ≥98%，黄褐 75%–98%，橙色 50%–75%，红色低于 50%，浅灰表示设备还没开始上报。土壤水分均值用连点折线展示，每个圆点对应一个有读数的时间片，点间用直线连接；相邻读数相隔超过 3 小时就断开，不补画中间值。
3. 鼠标悬停色条，或点一下色条后用左右方向键（Home / End 跳到首尾），下方会读出该时段的时间、正常上报台数、健康度和水分均值。
4. “作业流水线”四张卡对应巡田上报、灌溉作业、植保防治、收获记录，标出待处理、受阻和最近一次回执或记录的时间；卡片使用纸笔、阀门水滴、叶片喷雾器、穗束收纳筐四组双元素线描图标。点击卡片时，原卡片会平滑拉伸到页面内容区，再进入相应页面；系统不支持共享元素转场或开启了减少动态效果时会直接切换。
5. “地块 × 日期”每格是一天：绿色为当天读数都在设备配置的上下限内，橙色为有读数低于下限，蓝色为有读数高于上限，浅灰为有读数但设备没设上下限，空白为无读数。没有土壤水分设备的地块标“未布设监测”。

运行概览只读取已保存的设备读数和农事记录，是快照而非实时田间状况；上下限来自设备台账的配置，不是农学标定值。

## 表单与输入

- 打字过程中不报错。离开一个字段后，如果内容不符合要求，原因写在字段下方（例如“面积（亩）不能小于 0.01”）；改对后立即消失。
- 点保存时如果还有未填或不合规的字段，会逐个写出原因，光标跳到第一个问题字段并轻轻摇动（手机上同时轻振）。保存按钮不会因为没填完而变灰，点下去就知道缺什么。
- 手机键盘按字段类型弹出：面积、产量、能力等只能为正数的字段弹出数字键盘，整数字段不带小数点；允许负数的阈值字段保留带负号的键盘；搜索框的回车键显示为“搜索”；租户代码和账号不自动大写、不做拼写检查。
- 日期字段统一使用磐隐样式的日历容器：点击输入框或日历图标展开月份网格，可切换月份、清除日期或选择今天；当前日期用高亮底色显示，超出字段允许范围的日期不可选。
- 操作完成后统一给出带信息图标的提示：刷新、保存等常规结果在右下角显示；农场资料、平面图、模拟运行和任务完成等重要结果显示在页面中上方。
- 触屏设备上，按钮、输入框和下拉框高度不低于 44 像素；表格里的文字按钮、卡片里的“查看…”链接和地图设备标记都扩大了可点区域，外观不变。
- 列表里的数字按千分位显示，例如产量 5,280 kg。
- 手机上，地块、种植计划、生产记录、设备台账等列表的每一行显示为一张卡片（设备卡片以设备名称和编码为标题），左边是字段名、右边是内容，不再横向挤压；当前角色在某一行没有可做的操作时不显示空的“操作”行。

## 空状态与转场

- 列表、农场档案、设备台账、今日农场和页面搜索没有内容时，会说明原因并给出下一步：搜索无结果可“清除搜索”，筛选为空可“清除筛选”或“查看全部任务”，没有数据时可直接“新增第一条…”。需要先有地块的记录（种植计划、生产记录）会先引导到地块管理。
- 在农场档案点击农场图片，图片会放大过渡到工作台地图；点“← 返回农场”再收回到卡片。浏览器不支持或系统设置为“减少动态效果”时直接切换。
- 设备台账的设备行、农场工作台的点位/告警入口，以及今日农场的任务卡打开详情或处理记录时，详情容器会从来源卡片自然展开；浏览器不支持或系统设置为“减少动态效果”时直接打开。
- 登录时账号或密码不正确，登录表单会轻轻摇动一下，原因写在按钮上方。
- 对话框、命令面板和设备详情滚到底时不会带动背后的页面；横向滚动表格时不会触发浏览器的滑动返回。

## 新建自己的农场

管理员在农场概览点击“新增农场”，填写名称、区域说明、经营类型和说明。随后在“地块管理”建立地块，填写面积和作物，再回到农场图片进入工作台。新农场不会自动填入演示历史数据。

管理员点击“编辑平面图”，选择地块，再点击“绘制边界”。在图中依次点击至少三个顶点，点击“完成边界”，最后“保存平面图”。可以撤销顶点或清除边界。自相交、越界、面积过小的多边形会被拒绝。

平面坐标范围为 X=0–1000、Y=0–700，左上角为原点。这是用于管理的本地布局，不是经纬度或测绘成果；面积以地块档案填写的亩数为准。地图可以缩放、拖动、切换地块/设备/标签图层并回到全图。保存采用版本校验，其他人修改后应刷新再编辑。

## 新增、定位和维护设备

从工作台或“设备台账”点击“新增设备”。填写名称、租户内唯一编码、所属农场、关联地块、设备类型、接入方式、使用状态、预期上报周期、型号和说明。支持气象站、土壤站、水务设备、网关和其他设备；可配置多个监测指标及各自的告警上下限。

可以填写平面 X/Y 坐标，也可以先留空，保存后进入农场地图，点击“编辑平面图”→选择设备→“点击定位”，在地图点击安装位置并保存。已有标记可以拖动。设备既可关联地块，也可位于农场公共区域。

设备台账支持农场、类型、上报状态和关键词筛选，每页显示 15 台。点击设备名称打开详情，点击农场名返回该农场工作台。管理员可编辑配置、增加指标、修改阈值或停用设备。为保留历史关系，已有指标不能直接移除，设备不能直接改属另一农场。

## 三种数据接入方式

| 接入方式 | 操作 | 数据来源 |
|---|---|---|
| 本地模拟 | 在详情点击“立即模拟采集全部指标” | SIMULATED；仅用于演示 |
| 人工录入 | 在详情填写已配置指标，点击“保存监测记录” | MANUAL；操作人填写 |
| HTTP 上报 | 管理员生成设备凭据，由设备或网关 POST 数据 | HTTP_PUSH；通用接入接口 |

HTTP 凭据只在生成时显示一次，按 4 位一组显示便于核对，点“复制凭据”即可复制完整原文；重新生成会立即撤销旧凭据。详细请求格式见 [设备接入接口](设备接入接口.md)。设备处于维护或停用状态时，后端拒绝新的采集和上报。当前没有连接实体硬件，也没有厂商云、MQTT、视频或远程水泵控制功能。

## 告警与数据含义

数值越过指标配置的阈值后产生告警。在设备详情点击“确认”或“记录处理”，在弹出的对话框里填写说明（必填，对话框顶部显示告警内容）；新数据恢复范围内后，活动告警自动关闭。迟到的历史数据不会覆盖当前告警状态。

上报状态按接收时间与预期周期判断：超过三倍周期且至少 180 秒未收到数据，显示“超时未报”。这不是物理网络连通性检测。历史趋势按分钟或小时聚合，保留平均值、最小值、最大值和样本数量；CSV 导出相同范围的聚合结果。生产统计来自登记记录，不是预测产量。

## 权限与数据保留

管理员可维护地图、档案、设备凭据和成员；操作员可登记监测、产量并处理农事和告警；查看者只能查询。平台账号只管理租户状态。不同租户不能读取或关联对方的农场、地块、设备和告警。

数据库保存在 `backend/data`。升级采用新增表并回填旧设备档案的方式；首次开启丰富演示场景时，仅在 demo-a/demo-b 增加虚构农场，重复启动不会重建这些场景。启动前可设置 `FARM_DEMO_RICH=false` 关闭新增丰富场景。
