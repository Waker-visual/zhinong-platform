# WebGL 开发包资产来源

本包的程序来自本仓库 `unity/FarmScene`，由 Unity 6000.6.5f1 编译。包内包含 Unity WebGL 运行所需输出；Unity 产品及运行时权利归各自权利人，本项目不为第三方内容另行授予许可。

部分树木、农机和建筑网格、材质来自项目维护者提供的 [CleverFarm 虚拟农场](https://virtual.cleverfarm.ag/) 2026-10-13 参考捕获。原始捕获未附许可文本；2026-10-14，项目维护者明确确认已取得这些模型及卫星纹理的公开分发授权，并要求上传当前完整 Build。该确认是本次分发依据，不是将原素材改授为开源或公共领域。版权仍归原权利人；本包不包含原站源码、账号、商标页面或完整捕获材料。

卫星对齐场景中的林带与林地树木、农房、长条仓棚、塑料大棚、电杆和草捆由本项目 `tools/blender/build_farm_art.py` 在 Blender 中程序化生成（`unity/FarmScene/Assets/Resources/FarmArt`），属于项目自制资产，不来自参考捕获。农机与气象站等设备模型仍可能使用上段所述参考网格。

固定卫星影像由应用既有 Esri World Imagery 缓存合成，保留 Esri、Vantor、Earthstar Geographics、GIS User Community 署名。三维地面由 `tools/scene/classify_landcover.py` 从该影像推定的地表分类图（积水、作物成熟度、道路、田埂与作物行方向）程序化绘制，分类图属于影像派生数据，同样不提交 Git 并沿用上述署名；照片本身仅在缺少分类图时作为回退地表，并以较低分辨率打包。影像不是实时画面，地表分类、地形与遮挡结构均为推定，不能作为土地权属或测绘依据。应用中的田块、设备、作业记录均为虚构演示数据，按登录权限在运行时传入。
